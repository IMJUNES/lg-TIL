# 탄탄한 백엔드 기초, Java

2026.10.20.

## 1. 배운 내용

Java는 객체지향 프로그래밍(OOP) 언어이고 앞으로 배울 Spring Boot를 이용한 백엔드 개발에도 사용된다는 걸 배웠다.

**클래스와 인스턴스**: 클래스는 객체를 만들기 위한 틀이고 인스턴스는 그 틀로 실제 만든 객체다. 클래스에는 데이터를 담는 변수와 특정한 일을 하는 메서드가 있다.

**Java 실행 과정**: Java를 개발하려면 JDK가 필요하고 만든 프로그램은 JVM을 통해 실행된다. 작성한 코드를 실행할 수 있는 형태로 바꾸는 과정을 컴파일이라고 한다.

**변수와 데이터 타입**: 변수는 데이터를 담는 공간이고 숫자와 문자 그리고 참과 거짓처럼 값의 종류에 따라 타입이 다르다. 문자 하나를 쓸 때와 여러 글자로 된 문자열을 쓸 때 사용하는 따옴표도 다르다는 걸 배웠다.

**전역변수와 지역변수**: 변수는 작성한 위치에 따라 전역변수와 지역변수로 나뉜다. 블럭(메서드) 밖에서 작성한 변수는 여러 블럭에서 사용할 수 있고 블럭 안에서 작성한 지역변수는 해당 블록을 벗어나면 사용할 수 없다는 걸 배웠다.

**변수이름 작성 규칙**: Java는 대소문자를 구분하고 클래스의 이름은 파일 이름과 대소문자까지 정확히 같아야 한다. 클래스 이름을 대문자로 시작하거나 참과 거짓을 나타내는 변수 이름 앞에 is를 붙이는 것은 개발자들 사이의 암묵적인 룰이다.

마지막에 나온 응집도와 결합도는 예전에 소프트웨어공학 공부를 할 때 배웠던 내용이라 반가웠다. 그때는 시험을 위해 외웠는데 이번에는 실제 프로그램을 설계할 때 어떻게 쓰이는지 들어보니 더 쉽게 이해할 수 있었다.
