# Step 4. 생동감 있는 화면, 프론트엔드 (React)

2026.10.21

## 1. 배운 내용

이번에는 이전에 HTML, CSS, JavaScript로 만들었던 로그인 페이지를 React로 다시 만들어보았다.

실습을 위해 먼저 Node.js를 설치하고, React 프로젝트를 생성하면서 필요한 패키지들도 함께 설치했다.

React는 웹 화면을 만들 때 사용하는 JavaScript 라이브러리다. 기존에는 HTML로 화면을 만들고 JavaScript로 기능을 추가했다면, React에서는 컴포넌트라는 단위로 화면과 기능을 나눠서 만들 수 있다는 점을 배웠다.

사용자가 입력한 아이디와 비밀번호는 `useState`를 이용해 관리하고, 로그인 버튼을 누르면 입력값을 확인하도록 만들었다. 또한 별도의 css 파일을 만들지 않고도 한 파일안에서 style을 사용해 직접 디자인을 적용할 수 있다는 점도 알게 되었다.


## 2. 실수

강의를 보면서 코드를 직접 따라 쓰다 보니 작은 오타 때문에 오류가 자주 발생했다.

- 변수 이름 작성 실수: 같은 값을 사용하는데도 어떤 곳에서는 `userid`, 다른 곳에서는 `userId`처럼 이름을 다르게 적어서 오류가 발생했다. 이런 실수가 몇 번 반복되면서 변수 이름을 일관성 있게 작성하는 것도 중요하다는 걸 알게 됐다. 앞으로는 나만의 이름 작성 규칙을 정해서 비슷한 실수를 줄여야겠다고 생각했다.
- 사용하지 않는 코드 경고: 선언만 해두고 사용하지 않은 변수나 불러오기 코드 때문에 경고가 발생했다. 필요 없는 부분을 정리하거나 실제로 사용하도록 수정했다.
- 괄호 때문에 생긴 오류: 중괄호(`{}`)를 잘못 닫아서 코드가 정상 실행되지 않는 문제가 있었다. 함수가 시작하고 끝나는 위치를 다시 확인해서 해결했다.

## 3. 느낀점


1단원에서 만들었던 로그인 화면을 React로 다시 만들어보니 코드 작성 방식이 많이 달랐다.

코드가 길어서 강의를 보면서 하나하나 따라 쓰는 게 생각보다 힘들었다. 글자 하나나 괄호 하나만 빠뜨려도 오류가 발생해서 중간중간 막히기도 했다. 그래도 vs code에서 tab 키를 누르면 코드를 자동으로 완성해주는 기능이 있었고, 컴파일할시 오류가 발생하면 오타가 줄위치도 알려줘서 편리햇다
